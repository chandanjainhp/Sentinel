Suggested test sequence

Verify each stage in the Sentinel application.

1. Run in dry-run mode; verify telemetry changes.
2. Configure registered site, machine and sensor IDs.
3. Enable forwarding and confirm HTTP acceptance.
4. Send normal readings until the coverage gate opens.
5. Run the vibration-ramp scenario and watch predictions.
6. Test overheating, overload and sensor dropout.
7. Stop forwarding and inspect queue recovery after a service outage.
